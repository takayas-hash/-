# 予算差異アナライザー

売上集計表（当年・前年）を読み込み、店舗ごとの売上予算の達成・未達要因を分析して、月初報告用のコメント下書きを自動作成するツールです。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge）で開く
2. 「ファイルを選択」で、システムから出力した**売上集計表の当年分・前年分の2ファイル**をまとめて選ぶ（ドラッグ＆ドロップも可）
   - CSV（UTF-8 / Shift-JIS）・Excelどちらも可。どちらが当年かは日付から自動判定
   - 任意で **値引詳細** のCSVも一緒に選ぶと、値引内訳の分析が加わります（ファイルの種類は見出しから自動判別）
   - 従来の管理用 .xlsm 1ファイルでも動きます（`貼①【集計表】`／`貼①【集計表】 (前年)` を使用）
3. エリア全体・店舗別のコメントが表示されるので、必要に応じて編集してコピー
   - 「簡潔版／詳細版」で長さを切り替え
   - 「全店コメントを一括コピー」は `店舗名⇥コメント` 形式。Excelにそのまま貼り付け可能

## データの保存

読み込んだデータはこのブラウザ内（IndexedDB）に保存され、次回はファイルなしで前回の分析が表示されます。

- 毎日の更新は **当年の売上集計表だけ** 入れればOK。前年データ・値引詳細は保持されます
- 前年分だけを入れ直すと前年データだけが差し替わります（当年より古い月を自動判別）
- 月が変わり当年が翌月になると、月の合わない前年データ・値引詳細は自動で外れます（前年同月分を入れ直してください）
- 「保存データを削除」で消去。表示設定（直営のみ／全店、簡潔／詳細）も記憶します
- 保存先はブラウザごと（PCとスマホ、別のブラウザでは共有されません。シークレットウィンドウでは残りません）

ファイルはブラウザ内だけで処理され、外部へ送信されません（Excel読み込み用ライブラリ SheetJS のみ CDN から取得）。

## 使用するデータ

| ファイル | 用途 |
|---|---|
| 売上集計表（当年） | 当月の日別・店舗別実績（純売上高、客数、売上/客数の月次予算、天気、曜日区分、時間別売上・客数） |
| 売上集計表（前年） | 前年同月の同形式データ（前年比、時間帯の予算按分に使用）。なくても動くが前年比は出ない |
| 値引詳細（任意） | 受取内訳＝値引 の行を使い、値引の種類別（アプリ会員・チラシ・SNS・優待券・従業員食事など）の金額と件数を集計 |

列は見出し名（「純売上高(合計)」「売上月次予算」「時間別売上19時(オーダー時)」など）で探すため、列位置が変わっても動きます。

## 対象店舗

既定は**直営店のみ**（売上集計表の「FC区分」が「直営」で始まる店舗）。画面上部の切り替えで全店にも戻せます。

## 分析内容

| 分析 | 方法 |
|---|---|
| 要因分解 | 客数要因＝(客数実績−客数予算)×予算客単価、単価要因＝(実績客単価−予算客単価)×客数実績。合計は予算差と一致 |
| 曜日区分別 | 平日／休前日／土曜／日祝日ごとの予算比・予算差・平均日販（前年比較、暦差の指摘） |
| 曜日別 | 月〜日の予算比・予算差 |
| 時間帯別 | ランチ(〜14時)／アイドル(15–16時)／ディナー前半(17–18時)／ディナーピーク(19–20時)／レイト(21時〜)。時間帯の予算は「前年同月・同じ曜日区分の時間帯構成比」で日予算を按分 |
| 曜日区分×時間帯 | ヒートマップで最大の未達ポイントを特定 |
| 共通の不振日 | 対象店の85%以上が予算比85%未満、かつ同じ曜日区分の月平均より15pt以上低い日を外部要因の可能性として切り分け |
| データ確認 | 売上0の日（休業 or データ欠落）を検出し、除いた場合の予算比も表示 |
| 客単価の前年差 | 値引前単価の変化と、1人あたり値引の変化に分解（値引率の前年比較） |
| 予算前提の確認 | 予算の想定客単価が前年実績と12%以上ずれている場合に指摘 |
| 値引内訳（任意） | 値引の種類別構成比、チラシ利用件数、最大の値引施策 |

月の途中で読み込んだ場合は、実績のある最終日までの期間で集計します。
