# 予算差異アナライザー

売上集計表（当年・前年）を読み込み、店舗ごとの売上予算の達成・未達要因を分析して、月初報告用のコメント下書きを自動作成するツールです。

## ウェブアプリ版（Google Apps Script）

共有ドライブのフォルダに置いたファイルを自動で読み込むウェブアプリとしても使えます。設定手順は [gas/SETUP.md](gas/SETUP.md)。

## 使い方

1. **`予算差異アナライザー.html`** をダブルクリックしてブラウザ（Chrome / Edge）で開く
   - Excel読み込み用のライブラリ（SheetJS）を埋め込んだ1ファイル版です。インターネットに接続していなくても動きます。メールやTeams、共有フォルダでそのまま配れます
   - `index.html` は同じ内容で、ライブラリをインターネットから読み込む軽量版です
2. 「ファイルを選択」で、システムから出力した**売上集計表の当年分・前年分の2ファイル**をまとめて選ぶ（ドラッグ＆ドロップも可）
   - CSV（UTF-8 / Shift-JIS）・Excelどちらも可。どちらが当年かは日付から自動判定
   - 任意で **値引詳細** のCSVも一緒に選ぶと、値引内訳の分析が加わります（ファイルの種類は見出しから自動判別）
   - 従来の管理用 .xlsm 1ファイルでも動きます（`貼①【集計表】`／`貼①【集計表】 (前年)` を使用）
3. エリア全体・店舗別のコメントが表示されるので、必要に応じて編集してコピー
   - 「簡潔版／詳細版」で長さを切り替え
   - 「全店コメントを一括コピー」は `店舗名⇥コメント` 形式。Excelにそのまま貼り付け可能
   - コメントは見出し（前月の課題・着地見込み・客数・客単価・値引・曜日・時間帯など）ごとにまとめて表示。「テキストで編集」で文章のまま直せます（コピーは文章のまま）

## 訪問資料（PDF）

FC店のオーナー訪問用に、1店舗あたりA4横2ページ（売上1ページ・原価1ページ）の資料を作れます。文字は結論だけにして、あとは表とグラフで見せます。

- 店舗詳細の「訪問資料（PDF）」：表示中の店舗。上部の「FC全店の訪問資料（PDF）」：表示中のFC店すべて。FC企業別タブの「この企業の訪問資料（PDF）」：その企業の全店（1店舗2ページずつ、まとめて1つのPDF）
- 各ページの上に結論（3行まで。予算比・前年比、主な要因、着地見込みまたは前年を最も下回った時間帯／原価率理論差、ロス率、1人あたり原価）。結論の文は画面上で直接書き換えられる
- ①売上：主要数字、予算差の要因（予算→客数要因→単価要因→実績）、日別の予算比、曜日区分別（予算比・前年比）、時間帯別の前年比（色付きの表）
- ②原価：主要数字、当店と平均・前年の比較（原価率・仕入率・ロス率・1人あたり原価）、原価率の推移（原価管理表）、曜日別のロス額、食べ放題の分類別1人あたり原価、コース構成と飲み放題比率（データのあるものから4つまで）
- データがない図は出さず、残りの図を大きく並べます。「印刷・PDF保存」→送り先「PDFに保存」で保存（A4・横、余白なし）。他の店舗名は載りません（平均は表示中の対象店の平均）

## 飲み放題比率

メニュー別（ABC分析）の「コース」分類にある「〜飲み放題」の注文数 ÷ コースの注文数（どちらも大人・シニア・子どもを含む人数）。名前に「ソフト」が入るもの（ソフトドリンク飲み放題・Ｌソフトドリンク飲み放題）をソフトドリンク、それ以外（生ビール飲み放題など）をアルコールとして分けます。原価分析タブのコース構成（帯グラフ右端の「飲」、表の列）、コメント、訪問資料の2ページ目に出ます。

## データの保存

- **月ごとに保存します。** 前月（確定）と当月（途中経過）を両方持てるので、上の「分析する月」で切り替えます（2か月以上あるときだけ表示）。新しい4か月分まで残ります
- ファイルはそれぞれの月に自動で振り分けます。売上集計表・メニュー別・値引詳細は、12か月前のものを「その月の前年分」として扱います（例：2025年10月 → 2026年10月の前年）
- 売上集計表がまだない月のファイル（ABCなど）は保存だけしておき、その月の売上集計表を入れると分析に使います
- 時給データ・標準比マスタは全部の月で共通です
- **予測月**：売上の実績がまだない月（例：11月中旬に入れた12月の売上集計表）は「予測」として表示します。売上・客数＝その月の予算×直近の実績の月の曜日区分別の予算比（客数予算比）、労働時間・雑給＝その月の勤務スケジュール表、標準比＝客数見込み×勤務予定。原価・採用定着・時間帯・前月の課題・訪問資料は実績が出てから

読み込んだデータはこのブラウザ内（IndexedDB）に保存され、次回はファイルなしで前回の分析が表示されます。

- 毎日の更新は **当年の売上集計表だけ** 入れればOK。前年データ・値引詳細は保持されます
- 前年分だけを入れ直すと前年データだけが差し替わります（当年より古い月を自動判別）
- 元のファイルも一緒に保存しているため、ツールが更新されて読み取り項目が増えても、次に開いたときに自動で読み直します
- 「保存データを削除」で消去。表示設定（直営のみ／全店、簡潔／詳細）も記憶します
- 保存先はブラウザごと（PCとスマホ、別のブラウザでは共有されません。シークレットウィンドウでは残りません）

ファイルはブラウザ内だけで処理され、外部へ送信されません。

## 使用するデータ

| ファイル | 用途 |
|---|---|
| 売上集計表（当年） | 当月の日別・店舗別実績（純売上高、客数、売上/客数の月次予算、天気、曜日区分、時間別売上・客数） |
| 売上集計表（前年） | 前年同月の同形式データ（前年比、時間帯の予算按分に使用）。なくても動くが前年比は出ない |
| メニュー別 ABC分析（任意・当年／前年） | 中分類・メニューごとの予定原価・販売数・かしょく重量・総客数。原価率、1人あたり皿数・喫食量・原価の分析に使用。期間の終了日で当年分・前年分を自動判別 |
| 原価管理表（任意） | 店舗ごとのシートに、値引前後の売上・前月/当月棚卸高・当月仕入高・原価・値引前原価率・理論原価率・原価率理論差・ロス込原価率理論差、大分類別の仕入/原価、13か月の推移。1ファイルに全店分（.xls）。同じ店舗は新しいファイルで差し替え |
| タイムカード表（任意・CSV） | 個人別・日別の確定労働実績（労働時間・残業時間・深夜時間）。見出し「従業員コード」「確定出勤」「労働時間」で判別。年月は「月度」列（Nov-26 など） |
| 勤務スケジュール表（任意・CSV） | 個人別・日別の予定労働時間（休憩を除いた「労働時間(W/S)」）。確定日より後の見込みに使う |
| 時給データ（任意・店長資料の時給一覧 .xlsx） | 社員番号・時給。パートの雑給の計算に使う。月が変わっても残し、新しいファイルで差し替え |
| 値引詳細（任意・当年／前年） | 受取内訳＝値引 の行を使い、値引の種類別（アプリ会員・チラシ・SNS・優待券・従業員食事など）の金額と件数を集計。日付で当年分・前年分を自動判別 |

列は見出し名（「純売上高(合計)」「売上月次予算」「時間別売上19時(オーダー時)」など）で探すため、列位置が変わっても動きます。

## 対象店舗

画面上部で切り替えられます。選んだ内容は次回も記憶します。

- **営業部**：ファイルに複数の営業部が含まれる場合だけプルダウンが出ます（ブロック長向け）。「すべての営業部」を選ぶと、全体コメントに営業部別の予算比が入り、店舗一覧に営業部の列が出ます
- **直営のみ／FCのみ／全店**：売上集計表の「FC区分」列で判定（「直営」で始まる＝直営、「FC」で始まる＝FC）。各ボタンに店舗数を表示し、0店の区分は押せません。FC店しかないデータなら自動でFCのみになります

店舗名・店舗コードは決め打ちしていないため、同じ形式のデータであればどのエリアでも使えます。

## 原価の基準

原価分析の率は、社内の原価管理表と同じく **値引前売上高（純売上高＋値引）** を分母にしています（理論原価率・ロス率・仕入率）。

## 画面の構成

上部のタブで **売上分析** と **原価分析** を切り替えます。コメントもタブごとに別々に作成され、一括コピーは表示中のタブのコメントが対象です。

- 売上分析：予算差の要因、曜日区分・時間帯、値引
- 原価分析：原価率・喫食量・皿数（前年比較グラフ）、コース構成（帯グラフ）、ロス、理論差（概算）

## 分析内容

| 分析 | 方法 |
|---|---|
| 着地見込み（月の途中のみ） | 実績＋残り日の日予算×ここまでの曜日区分別の予算比（売上0の日は除く。実績が2日未満の区分は全体の予算比）。必要日販＝(月予算−実績)÷残り日数、残り期間の必要予算比＝(月予算−実績)÷残り日の予算。月末までの予算が売上集計表にない日は同じ曜日区分の平均日予算で補う。詳細版では前年の残り期間実績×前年比の見込みも参考表示。店舗詳細に累計売上の推移グラフ |
| 着地見込みの売上 | 残りの日は店長の売上日別予測を優先（予測のない店・日は予算×ここまでの曜日区分別の予算比） |
| 要因分解 | 客数要因＝(客数実績−客数予算)×予算客単価、単価要因＝(実績客単価−予算客単価)×客数実績。合計は予算差と一致 |
| 前月の課題のその後 | 連続する2か月（例：10月確定と11月途中）を保存しているとき、前の月に未達だった曜日区分（未達額の大きい2つ）・時間帯（2つ）・最大の未達ポイント（曜日区分×時間帯）・客数予算比・ロス率が、次の月にどうなったか。解消（予算達成）／改善中（+2pt以上）／横ばい／悪化（▲2pt以上）。コメント（全体・店舗）と店舗詳細の表に表示。どちらの月を表示していても出る |
| 曜日区分別 | 平日／休前日／土曜／日祝日ごとの予算比・予算差・平均日販（前年比較、暦差の指摘） |
| 曜日別 | 月〜日の予算比・予算差 |
| 時間帯別 | ランチ(〜14時)／アイドル(15–16時)／ディナー前半(17–18時)／ディナーピーク(19–20時)／レイト(21時〜)。**前年データがあれば前年比で評価**（時間帯の予算は按分の参考値のため）。前年がないときだけ、前年同月・同じ曜日区分の時間帯構成比で日予算を按分した予算比 |
| 曜日区分×時間帯 | ヒートマップ。前年データがあれば1日あたりの前年比（曜日区分ごとの日数の違いを除く）と1日あたりの前年差。前年から最も落ちているところ（1日あたりの差×日数が最大）をコメント |
| 共通の不振日 | 対象店の85%以上が予算比85%未満、かつ同じ曜日区分の月平均より15pt以上低い日を外部要因の可能性として切り分け |
| データ確認 | 売上0の日（休業 or データ欠落）を検出し、除いた場合の予算比も表示 |
| 客単価の前年差 | 値引前単価の変化と、1人あたり値引の変化に分解（値引率の前年比較） |
| 予算前提の確認 | 予算の想定客単価が前年実績と12%以上ずれている場合に指摘 |
| 原価率理論差（原価管理表） | 値引前原価率−理論原価率、ロス込原価率理論差（さらに値引前ロス率を引いた値）。直近3か月平均、12か月の平均と比べた振れ、1年を通した恒常的なマイナス／プラスを指摘。推移グラフ（理論・実際の原価率、ロス込理論差）と大分類別の原価比（平均比較） |
| 理論差（概算） | 仕入率（仕入高÷純売上高）−理論原価率。ロス率とそれ以外（在庫の増減・使用量の差など）に分ける。原価管理表がない場合だけ使う。食材別の理論差データは使わない |
| コース構成 | 年齢区分を合算したコースの種類ごとの構成比。原価タブで店舗別の帯グラフ（プレミアム比率順）、店舗詳細で当年・前年・対象店平均を比較 |
| ロス | 廃棄額÷純売上高（売上集計表の「廃棄額」列。元データではDJ列）。対象店平均・前年と比較し、突出日（1日平均の3倍以上かつ1万円以上）と曜日の偏り（1曜日に30%以上）を指摘 |
| 原価率（任意） | 原価÷純売上高（売上集計表の「原価」列＝メニュー別の予定原価×販売数）。対象店平均・前年との差を「1人あたり原価（喫食）」と「客単価」の影響に分解 |
| 喫食量・皿数（任意） | 食べ放題フードの1人あたり皿数・g、精肉の皿数・g、ドリンク杯数。分類別・品目別に平均との差を表示。前年メニュー別があれば、1人あたり原価の前年差を「量」と「原価単価（原価改定など）」に分解 |
| 値引による誘客の前年差（任意） | 分類別の利用件数の前年差（従業員食事は除く）と、1組あたり人数で換算した客数差（推計）。1人あたり値引の前年差を分類別に分けた客単価への影響 |
| 労働時間の見込み（人タブ） | 確定日（実績がその日の予定人数の半分以上ある最後の日）までタイムカード実績、以降は勤務スケジュールの予定。予定の合計が同じ曜日区分の実績平均の半分未満の日は「予定未作成」とみなし実績平均で補う。スケジュール表がなければタイムカードの勤務予定から「拘束8時間以上は休憩1時間」で見込む |
| 雑給（人タブ） | パートの労働時間×時給。割増は残業（1日8時間超）25%・深夜（22–5時）25%、重なる時間は50%。時給データにない人は店舗のパート平均時給。雑給率＝雑給の着地見込み÷売上の着地見込み |
| 残業アラート（人タブ） | 個人別に月の残業（実績＋予定）を見込み、45h以上を注意、60h以上を要対応として表示 |
| 標準比（人タブ） | 標準比マスタ（見込君 .xlsx。通常店用・特急レーン店用の2つ）の卓数ごとの切片・予算標準比・祝日を使い、見込君と同じ式で日別の標準時間を計算（レーン店は 切片＋客数×店舗ごとの変数）。標準比＝労働時間÷標準時間。確定日までは実績、以降は客数見込み×勤務予定で着地を見込み、予算標準比に収めるための削減時間（雑給換算）を表示。店舗設定（ランチ営業・T8台数・営業時間・自動案内）は画面で変更できる |
| 採用・定着（採用・定着タブ） | 個人別の月ごとの総労働時間・出勤日数を表示。タイムカードと時給データ（入社年月日）を月ごとに積み上げ（ブラウザ版はこのブラウザ、ウェブアプリはエリアの「履歴データ」フォルダ）。パートを勤務期間（1か月未満／1か月〜半年／半年〜1年／1年以上）に分けた人数・平均労働時間（当月は見込みで月換算）、入社後の月数ごとの平均労働時間（戦力化）、新規採用（当月・前月入社）、退社（時給データから外れた人・退職日のある人、2か月勤務なしは「可能性」）、退社リスク注意（入社1年以内で、当月の時間が前の月の平均の70%以下、または当月のこれからの予定が実績ペースの70%以下。50%以下は要注意）。減り方を「出勤日数×1回あたりの時間」に分解し、日数が減っている（本人の都合の可能性→面談）／1回が短くなっている（シフトの組み方を確認）／両方 に分類 |
| 日別の標準比管理（人タブ） | 売上集計表の店長の客数予測（客数日別予測）と計画労働時間（社員／P/A労働時間日別予測）から、日ごとの計画標準比＝計画労働時間÷予測客数からの標準時間。過ぎた日は実績標準比も並べ、予算標準比を超える時間を表示。客数予測の当たり具合（実績÷予測）も。着地見込みは過ぎた日の実績＋これからの日の計画。タイムカード・勤務スケジュールがなくても売上集計表だけで動く |
| FC企業別（FC企業別タブ） | 店舗情報（店舗コード・経営企業名・担当AMの表）を読み込むと、FC店を経営企業ごとに集計。企業別の売上・予算比・予算差・着地見込み・達成店舗数・客数/単価要因・前年比・原価率理論差、企業を選ぶと店舗別の表と報告コメント、企業の全店分の訪問資料（PDF）。直営だけを表示中でも使える |
| 入社月ごとの推移（採用・定着タブ） | 直近6か月に入社したパートを入社月でまとめ、1か月目・2か月目…の平均労働時間と勤務人数を表示。直近2点で+10%以上＝順調、▲10%以上＝減っている。店舗一覧の「新人の伸び」で店ごとに比較 |
| 値引内訳（任意） | 値引の種類別構成比、チラシ利用件数、最大の値引施策 |

月の途中で読み込んだ場合は、実績のある最終日までの期間で集計し、月末の着地見込みと予算達成に必要な日販を表示します。
