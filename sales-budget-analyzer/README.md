# 予算差異アナライザー

売上集計表（当年・前年）を読み込み、店舗ごとの売上予算の達成・未達要因を分析して、月初報告用のコメント下書きを自動作成するツールです。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge）で開く
2. 「ファイルを選択」で、システムから出力した**売上集計表の当年分・前年分の2ファイル**をまとめて選ぶ（ドラッグ＆ドロップも可）
   - CSV（UTF-8 / Shift-JIS）・Excelどちらも可。どちらが当年かは日付から自動判定
   - 任意で **値引詳細** のCSVも一緒に選ぶと、値引内訳の分析が加わります（ファイルの種類は見出しから自動判別）
   - 従来の管理用 .xlsm 1ファイルでも動きます（`貼①【集計表】`／`貼①【集計表】 (前年)` を使用）
3. エリア全体・店舗別のコメントが表示されるので、必要に応じて編集してコピー
   - 「簡潔版／詳細版」で長さを切り替え
   - 「全店コメントを一括コピー」は `店舗名⇥コメント` 形式。Excelにそのまま貼り付け可能

## データの保存

読み込んだデータはこのブラウザ内（IndexedDB）に保存され、次回はファイルなしで前回の分析が表示されます。

- 毎日の更新は **当年の売上集計表だけ** 入れればOK。前年データ・値引詳細は保持されます
- 前年分だけを入れ直すと前年データだけが差し替わります（当年より古い月を自動判別）
- 月が変わり当年が翌月になると、月の合わない前年データ・値引詳細は自動で外れます（前年同月分を入れ直してください）
- 元のファイルも一緒に保存しているため、ツールが更新されて読み取り項目が増えても、次に開いたときに自動で読み直します
- 「保存データを削除」で消去。表示設定（直営のみ／全店、簡潔／詳細）も記憶します
- 保存先はブラウザごと（PCとスマホ、別のブラウザでは共有されません。シークレットウィンドウでは残りません）

ファイルはブラウザ内だけで処理され、外部へ送信されません（Excel読み込み用ライブラリ SheetJS のみ CDN から取得）。

## 使用するデータ

| ファイル | 用途 |
|---|---|
| 売上集計表（当年） | 当月の日別・店舗別実績（純売上高、客数、売上/客数の月次予算、天気、曜日区分、時間別売上・客数） |
| 売上集計表（前年） | 前年同月の同形式データ（前年比、時間帯の予算按分に使用）。なくても動くが前年比は出ない |
| メニュー別 ABC分析（任意・当年／前年） | 中分類・メニューごとの予定原価・販売数・かしょく重量・総客数。原価率、1人あたり皿数・喫食量・原価の分析に使用。期間の終了日で当年分・前年分を自動判別 |
| 食材別 理論差（任意・店舗ごと） | 品目ごとの棚卸・仕入・ロス・実使用量・理論使用量・理論差異。重いため1店ずつダウンロードしたCSVを追加で読み込む（店舗コードごとに保存・差し替え） |
| 値引詳細（任意・当年／前年） | 受取内訳＝値引 の行を使い、値引の種類別（アプリ会員・チラシ・SNS・優待券・従業員食事など）の金額と件数を集計。日付で当年分・前年分を自動判別 |

列は見出し名（「純売上高(合計)」「売上月次予算」「時間別売上19時(オーダー時)」など）で探すため、列位置が変わっても動きます。

## 対象店舗

画面上部で切り替えられます。選んだ内容は次回も記憶します。

- **営業部**：ファイルに複数の営業部が含まれる場合だけプルダウンが出ます（ブロック長向け）。「すべての営業部」を選ぶと、全体コメントに営業部別の予算比が入り、店舗一覧に営業部の列が出ます
- **直営のみ／FCのみ／全店**：売上集計表の「FC区分」列で判定（「直営」で始まる＝直営、「FC」で始まる＝FC）。各ボタンに店舗数を表示し、0店の区分は押せません。FC店しかないデータなら自動でFCのみになります

店舗名・店舗コードは決め打ちしていないため、同じ形式のデータであればどのエリアでも使えます。

## 画面の構成

上部のタブで **売上分析** と **原価分析** を切り替えます。コメントもタブごとに別々に作成され、一括コピーは表示中のタブのコメントが対象です。

- 売上分析：予算差の要因、曜日区分・時間帯、値引
- 原価分析：原価率・喫食量・皿数、ロス、理論差（食材別）と実原価の整合

## 分析内容

| 分析 | 方法 |
|---|---|
| 要因分解 | 客数要因＝(客数実績−客数予算)×予算客単価、単価要因＝(実績客単価−予算客単価)×客数実績。合計は予算差と一致 |
| 曜日区分別 | 平日／休前日／土曜／日祝日ごとの予算比・予算差・平均日販（前年比較、暦差の指摘） |
| 曜日別 | 月〜日の予算比・予算差 |
| 時間帯別 | ランチ(〜14時)／アイドル(15–16時)／ディナー前半(17–18時)／ディナーピーク(19–20時)／レイト(21時〜)。時間帯の予算は「前年同月・同じ曜日区分の時間帯構成比」で日予算を按分 |
| 曜日区分×時間帯 | ヒートマップで最大の未達ポイントを特定 |
| 共通の不振日 | 対象店の85%以上が予算比85%未満、かつ同じ曜日区分の月平均より15pt以上低い日を外部要因の可能性として切り分け |
| データ確認 | 売上0の日（休業 or データ欠落）を検出し、除いた場合の予算比も表示 |
| 客単価の前年差 | 値引前単価の変化と、1人あたり値引の変化に分解（値引率の前年比較） |
| 予算前提の確認 | 予算の想定客単価が前年実績と12%以上ずれている場合に指摘 |
| ロス | 廃棄額÷純売上高（売上集計表の「廃棄額」列。元データではDJ列）。対象店平均・前年と比較し、突出日（1日平均の3倍以上かつ1万円以上）と曜日の偏り（1曜日に30%以上）を指摘 |
| 原価率（任意） | 原価÷純売上高（売上集計表の「原価」列＝メニュー別の予定原価×販売数）。対象店平均・前年との差を「1人あたり原価（喫食）」と「客単価」の影響に分解 |
| 喫食量・皿数（任意） | 食べ放題フードの1人あたり皿数・g、精肉の皿数・g、ドリンク杯数。分類別・品目別に平均との差を表示。前年メニュー別があれば、1人あたり原価の前年差を「量」と「原価単価（原価改定など）」に分解 |
| 理論差（任意） | 理論使用量が登録されている食材だけを対象に、理論より多く／少なく使った品目の上位、中分類別の差。理論があるのに実使用0・実使用マイナス・理論の3倍以上の品目は確認対象として表示。登録品の不足分を同じ中分類の未登録品で使っている場合は「代替品の可能性」 |
| 実原価との整合（任意） | 理論原価（売上集計表の原価）＋理論差異＋理論未登録食材の実使用＋ロス＋理論原価のうち食材に紐づかない分＝実原価（食材の実使用＋ロス）。仕入高・ロスが売上集計表と一致しているかも照合 |
| 値引による誘客の前年差（任意） | 分類別の利用件数の前年差（従業員食事は除く）と、1組あたり人数で換算した客数差（推計）。1人あたり値引の前年差を分類別に分けた客単価への影響 |
| 値引内訳（任意） | 値引の種類別構成比、チラシ利用件数、最大の値引施策 |

月の途中で読み込んだ場合は、実績のある最終日までの期間で集計します。
