# ウェブアプリ（Google Apps Script）の設定手順

予算差異アナライザーを、社内の Google Workspace で開けるウェブアプリにする手順です。
最初に一度だけ設定すれば、あとは各AMが共有ドライブにファイルを置くだけで、URLを開くと最新の分析が表示されます。

所要時間：15分ほど

---

## 1. 共有ドライブにフォルダを作る

```
共有ドライブ
└ 予算差異アナライザー            ← このフォルダのURLを後で使う
   ├ 共通                         ← 時給データ・標準比マスタ（見込君）を置く。月1回差し替え
   ├ 髙谷エリア                   ← 売上集計表・タイムカード表・勤務スケジュール表などを置く
   ├ ○○エリア
   └ 過去                         ← 古いファイルの置き場（ウェブアプリは読まない）
```

- **フォルダ名「共通」「過去」はこのとおりに付けてください**（それ以外の名前のフォルダはすべてエリアとして扱います）
- 見られる範囲は**フォルダの共有設定**で決まります
  - AM：自分のエリアのフォルダと「共通」に閲覧権限
  - ブロック長：全エリアのフォルダと「共通」に閲覧権限
  - 時給データは個人情報のため、「共通」フォルダはAM以上だけに共有してください

### 各エリアのフォルダに置くファイル
| ファイル | 頻度 |
|---|---|
| 売上集計表（当年・前年同月）CSV | 当年は毎日〜週1で上書き、前年は月初に1回 |
| タイムカード表 CSV | 毎日〜週1で上書き |
| 勤務スケジュール表 CSV | シフトを作ったら上書き |
| 値引詳細・メニュー別・原価管理表（任意） | 月1回 |

- ファイル名は自由です。中身の見出しから種類を自動で判別します
- 同じ種類のファイルが複数あるときは、日付からいちばん新しい月を使います。前の月のファイルは「過去」フォルダに移しておくと読み込みが速くなります
- Excelをドライブに入れたときに「Googleスプレッドシートに変換」されていても読めます

---

## 2. Apps Script のプロジェクトを作る

1. https://script.google.com を開き、「新しいプロジェクト」
2. 左上の「無題のプロジェクト」を「予算差異アナライザー」に変更
3. **コード.gs**：中身をすべて消して、このフォルダの `Code.gs` の内容を貼り付け
4. 左の「ファイル」の「＋」→「HTML」→ 名前を `index` にする（`.html` は自動で付きます）
   中身をすべて消して、このフォルダの `index.html` の内容を貼り付け
5. 左の「⚙ プロジェクトの設定」
   - 「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
   - エディタに戻り、`appsscript.json` の中身を、このフォルダの `appsscript.json` の内容に置き換え
6. 「⚙ プロジェクトの設定」の下の方「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ：`ROOT_FOLDER_ID`
   - 値：「予算差異アナライザー」フォルダのURLの `folders/` の後ろの文字列
     （例：`https://drive.google.com/drive/folders/1AbCdEf...` なら `1AbCdEf...`）
7. 💾 保存

## 3. 公開（デプロイ）する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の歯車 →「ウェブアプリ」
3. 設定
   - 説明：初版
   - 次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー：**（会社名）内の全員**
4. 「デプロイ」→ 権限の確認画面で自分のアカウントを選んで「許可」
5. 表示された**ウェブアプリのURL**を開く → 動作確認
6. URLをAM・ブロック長に共有（初回だけ各自で「許可」を押してもらいます）

## 4. 更新するとき

ツールを更新したら `Code.gs` と `index.html` を貼り替えて、
「デプロイ」→「デプロイを管理」→ ✏ →「バージョン：新バージョン」→「デプロイ」。URLは変わりません。

## よくあること

| 症状 | 対処 |
|---|---|
| 「ROOT_FOLDER_ID が未設定です」 | 手順2-6 のスクリプト プロパティを確認 |
| 「見られるエリアのフォルダがありません」 | そのアカウントにエリアのフォルダが共有されているか確認 |
| 「Excel読み込み用ライブラリを取得できませんでした」 | 社内ネットワークで外部のライブラリが読めない場合です。`index.html` の代わりに、1つ上のフォルダの `予算差異アナライザー.html`（ライブラリ埋め込み版）の中身を貼り付けてください |
| 読み込みが遅い | 古いファイルを「過去」フォルダへ移す。時給データは全社分で大きいため、1〜2分かかることがあります |
| 標準比の店舗設定（ランチ営業・T8台数など） | 「人」タブの店舗詳細で変更すると、全員共通の設定として保存されます（スクリプト プロパティに保存） |

## しくみ（参考）
- 分析はすべて開いた人のブラウザの中で行います。サーバー（Apps Script）はドライブからファイルを渡すだけです
- 「アクセスしているユーザーとして実行」なので、本人がドライブで開けないファイルは読めません
- 権限：ドライブの閲覧（読み取りのみ）、スプレッドシートの変換用の外部通信、メールアドレスの表示
