# ウェブアプリ（Google Apps Script）の設定手順

予算差異アナライザーを、社内の Google Workspace で開けるウェブアプリにする手順です。
最初に一度だけ設定すれば、あとは各AMが共有ドライブにファイルを置くだけで、URLを開くと最新の分析が表示されます。

所要時間：15分ほど

---

## 1. フォルダを作る（マイドライブでも共有ドライブでも可）

```
予算差異アナライザー               ← ルート。このフォルダのURLを後で使う。だれにも共有しなくてよい
├ 共通                           ← 時給データ・標準比マスタ（通常店用・特急レーン店用）・店舗情報。月1回差し替え
├ 西一ブロック                     ← ブロック。ブロック長に「閲覧者」で共有
│  ├ 髙谷エリア                   ← AMに「編集者」で共有。売上集計表・タイムカード表・勤務スケジュール表などを置く
│  │  ├ 履歴データ               ← ウェブアプリが自動で作る（採用・定着の月ごとの履歴。消さないでください）
│  │  └ 過去                     ← 古いファイルの置き場（ウェブアプリは読まない。3.5 の自動整理で毎月自動で移る）
│  ├ 名越エリア
│  └ …
└ 西二ブロック
   └ …
```

- **フォルダ名「共通」「過去」「履歴データ」はこのとおりに付けてください**
- ルートの直下のフォルダのうち、中にフォルダ（「過去」「履歴データ」以外）があるものを**ブロック**、ないものを**エリア**として扱います。ブロックを作らず、ルートの直下にエリアを置いても動きます
- 見られる範囲は**フォルダの共有設定**で決まります（ルートは共有しません。共有すると中のすべてが見えてしまうため）
  - AM：自分のエリアのフォルダに**編集者**（ファイルを置くため。採用・定着の履歴もこのときに保存されます）、「共通」に閲覧者
  - ブロック長：自分のブロックのフォルダに**閲覧者**（そのブロックのエリアがすべて見えます）、「共通」に閲覧者
  - 時給データは個人情報のため、「共通」フォルダはAM以上だけに共有してください
- フォルダの一覧（どのブロックにどのエリアがあるか）は、ルートを開ける人（管理者）がウェブアプリを開いたときに自動で覚えます。**ブロック・エリアのフォルダを足したり名前を変えたりしたら、管理者が一度ウェブアプリを開く**（またはエディタで `refreshFolders` を実行）してください

### 今のフォルダ（ルートの直下にエリア）からブロックへ移すとき
1. `Code.gs` の `BLOCK_FOLDERS` に、ブロック名とその下のエリア名を書く（例：`{ '西一ブロック': ['河野エリア', '金エリア', '髙谷エリア'] }`）
2. エディタで `setupFolders` を ▶実行 → ブロックのフォルダができ、ルートの直下にある同じ名前のエリアのフォルダが**中身（履歴データ・過去を含む）ごと**ブロックの下へ移ります
3. ルートの「一般的なアクセス」を「制限付き」にし、ブロックのフォルダをブロック長に「閲覧者」で共有する（エリアのフォルダのAMの共有はそのまま残ります）
4. `checkSetup` を ▶実行して、ブロック／エリアの一覧とファイル数を確認

### 各エリアのフォルダに置くファイル
| ファイル | 頻度 |
|---|---|
| 売上集計表（当年・前年同月）CSV | 当年は毎日〜週1で上書き、前年は月初に1回 |
| タイムカード表 CSV | 毎日〜週1で上書き |
| 勤務スケジュール表 CSV | シフトを作ったら上書き |
| 値引詳細・メニュー別・原価管理表（任意） | 月1回 |

### 置いてもよいもの・読まないもの
- 読むのは各フォルダの**直下**にある CSV・Excel（.xlsx/.xlsm/.xls）・Googleスプレッドシートだけです。PDF・画像・Word などは読みません
- 種類のわからない表（シフトメモなど）が混ざっていても止まりません。「使わなかったファイル」として画面に出ます
- 1つのフォルダで読むのは更新日時の新しい40件までです。前の月の分は「過去」フォルダへ移してください（3.5 の自動整理を設定すると毎月自動で移ります）
- フォルダの中のフォルダ（「過去」など）は読みません

### 採用・定着の履歴（タイムカード・時給データの積み上げ）
- ウェブアプリを開くたびに、フォルダにあるタイムカード（どの月でも）と時給データを月ごとにまとめて、エリアのフォルダの「履歴データ」に保存します（1か月1店舗あたり数KB）
- **過去の月のタイムカードもエリアのフォルダに置いて一度開けば、履歴に入ります。** 入ったら「過去」フォルダへ移して構いません
- 時給データ（共通フォルダ）は毎月差し替えてください。前の月の資料から消えた人を「退社」として数えます
- **同じ月のタイムカードは何度入れ直しても大丈夫です。** 履歴は「月ごとに1つ」で、入れ直すたびにその月の分が新しい内容で上書きされます（足し算はされません）
- エリアのフォルダに同じ月のタイムカードが2つ以上あるときは、更新日時がいちばん新しいものだけを使います（画面に「古い方を使いませんでした」と出ます）。古い方は「過去」へ移すか削除してください
- 「履歴データ」フォルダは自動で作られる保存用です。CSVはここではなく、エリアのフォルダに置いてください（履歴データに置いたCSVは読みません）
- 月末後に、その月の最終のタイムカードを一度入れてください。入れなかった月は、最後に入れた日までの実績を月換算して使います

- ファイル名は自由です。中身の見出しから種類を自動で判別します
- 同じ種類のファイルが複数あるときは、日付からいちばん新しい月を使います。前の月のファイルは「過去」フォルダに移しておくと読み込みが速くなります
- Excelをドライブに入れたときに「Googleスプレッドシートに変換」されていても読めます

## 2. Apps Script のプロジェクトを作る

1. https://script.google.com を開き、「新しいプロジェクト」
2. 左上の「無題のプロジェクト」を「予算差異アナライザー」に変更
3. **コード.gs**：中身をすべて消して、このフォルダの `Code.gs` の内容を貼り付け
4. 左の「ファイル」の「＋」→「HTML」→ 名前を `index` にする（`.html` は自動で付きます）
   中身をすべて消して、このフォルダの `index.html` の内容を貼り付け
5. 左の「⚙ プロジェクトの設定」
   - 「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
   - エディタに戻り、`appsscript.json` の中身を、このフォルダの `appsscript.json` の内容に置き換え
6. 「⚙ プロジェクトの設定」の下の方「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ：`ROOT_FOLDER_ID`
   - 値：「予算差異アナライザー」フォルダのURLの `folders/` の後ろの文字列
     （例：`https://drive.google.com/drive/folders/1AbCdEf...` なら `1AbCdEf...`）
7. 💾 保存
8. **フォルダを作る（任意）**：`Code.gs` の上の方 `BLOCK_FOLDERS`（ブロック名とエリア名）を必要に応じて書き換え、上の関数の選択で `setupFolders` を選んで ▶実行。「共通」とブロック・エリアのフォルダが作られます（初回は権限の確認が出るので「許可」）
9. **設定の確認**：関数の選択で `checkSetup` を選んで ▶実行 →「実行ログ」に、見えているフォルダ・ファイルの数が出ます。`NG` が出たらその内容を直してください

## 3. 公開（デプロイ）する

> まず自分だけで試すなら：「デプロイ」→「デプロイをテスト」でテスト用のURLが出ます（自分にしか開けません）。問題なければ下の手順で公開します。

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の歯車 →「ウェブアプリ」
3. 設定
   - 説明：初版
   - 次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー：**（会社名）内の全員**
4. 「デプロイ」→ 権限の確認画面で自分のアカウントを選んで「許可」
5. 表示された**ウェブアプリのURL**を開く → 動作確認
6. URLをAM・ブロック長に共有（初回だけ各自で「許可」を押してもらいます）

## 3.5 月初の自動整理（任意・おすすめ）

毎月1日の朝5時台に、各エリアのフォルダから古いファイルを、そのエリアの「過去」フォルダ（月ごとのフォルダ）へ自動で移します。

- 移すのは、エリアのフォルダ直下で**最終更新が前月1日より前**のファイル
  （例：12月1日 → 10月以前に更新されたファイルを移す。11月・12月に入れたもの＝前月の確定分と当月分は残る）
- 「共通」「履歴データ」、フォルダの中のフォルダには触りません
- お知らせは送りません。移した結果は Apps Script の「実行数」（左のメニュー）で確認できます。間違って移ったものはエリアのフォルダへ戻してください

設定のしかた（エディタで実行）：
1. `previewArchive` を ▶実行 →「実行ログ」に、今動かした場合に移るファイルが出ます（移しはしません）
2. 問題なければ `installMonthlyArchive` を ▶実行（初回は権限の確認で「許可」）。これで毎月自動で動きます
3. すぐに一度整理したいときは `archiveOldFiles` を ▶実行。止めるときは `uninstallMonthlyArchive`

注意：自動整理は**設定した人の権限**で動きます。全エリアのフォルダでファイルを移せる人（共有ドライブの「コンテンツ管理者」以上）が設定してください。

## 4. 更新するとき

ツールを更新したら `Code.gs` と `index.html` を貼り替えて、
「デプロイ」→「デプロイを管理」→ ✏ →「バージョン：新バージョン」→「デプロイ」。URLは変わりません。

## よくあること

| 症状 | 対処 |
|---|---|
| 「ROOT_FOLDER_ID が未設定です」 | 手順2-6 のスクリプト プロパティを確認 |
| 「見られるエリアのフォルダがありません」 | そのアカウントにエリア（またはブロック）のフォルダが共有されているか確認 |
| 「フォルダの一覧がまだありません」 | 管理者が一度ウェブアプリを開くか、エディタで `refreshFolders` を実行 |
| 新しく作ったエリアが出ない | 管理者が一度ウェブアプリを開く（フォルダの一覧が更新されます） |
| 「Excel読み込み用ライブラリを取得できませんでした」 | 社内ネットワークで外部のライブラリが読めない場合です。`index.html` の代わりに、1つ上のフォルダの `予算差異アナライザー.html`（ライブラリ埋め込み版）の中身を貼り付けてください |
| 読み込みが遅い | 古いファイルを「過去」フォルダへ移す。時給データは全社分で大きいため、1〜2分かかることがあります |
| 標準比の店舗設定（ランチ営業・T8台数など） | 「人」タブの店舗詳細で変更すると、全員共通の設定として保存されます（スクリプト プロパティに保存） |

## しくみ（参考）
- 分析はすべて開いた人のブラウザの中で行います。サーバー（Apps Script）はドライブからファイルを渡すだけです
- 「アクセスしているユーザーとして実行」なので、本人がドライブで開けないファイルは読めません
- 権限：ドライブ（ファイルの読み取り、「履歴データ」への保存、月初の自動整理）、スプレッドシートの変換用の外部通信、メールアドレスの表示、自動整理の予約（トリガー）
