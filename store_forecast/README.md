# 日別客数予測ツール

時間帯別売上実績表（先月・先々月・前年当月）を貼り付けると、当月の日別・時間帯別の予測客数と客単価を出す Excel ツール。
「売上予測貼付用」シートは月次計画表の【事前】売上予測タブと同じ配置（F4:M34＝時間帯別の客単価・客数）。

- `日別客数予測ツール.xlsx` … 空のテンプレート（使い方はブック内「使い方」シート）
- `build_forecast_tool.py` … テンプレート生成スクリプト（祝日追加や時刻列の変更はここを編集して再生成）

```
python build_forecast_tool.py 出力.xlsx [先月データ.xlsx] [先々月データ.xlsx] [前年当月データ.xlsx]
```

## 予測式

予測客数 ＝ 予測ランチ ＋ 予測ディナー

| 要素 | 内容 |
|---|---|
| 営業区分 | 「設定」で平日／土日祝のランチ営業あり・なしを店舗ごとに指定（日ごとに変更可） |
| ディナー基準 | 先月・先々月の日タイプ別（月〜日＋祝）ディナー平均を 0.6:0.4 で加重平均 |
| ランチ基準 | ランチ営業した日だけの平均（夏休み等の平日ランチが平常月に混ざらない） |
| 季節係数 | 前年当月 ÷ 前年の先月・先々月（曜日別ディナー平均の比、祝日除く） |
| 前年同曜日 | 前年当月の364日前の実績 × 直近前年比 を直近ベースと 0.5:0.5 でブレンド（祝日絡みは除外） |
| トレンド係数・日別補正 | 手入力 |

## 客単価の予測

時間帯別客単価 ＝ 日タイプ×時間帯の基準客単価（先月・先々月の売上÷客数を 0.6:0.4 で加重平均）× 客単価の季節係数 × 客単価トレンド係数

- 時間帯はシステムの区分（ランチ11〜14時／アイドル15〜17時／ディナー18〜21時／ナイト22時〜）。「設定」の対応表で変更可
- 客数が最低客数（10人）未満の時間帯は全曜日合算の単価で代用
- 客単価の季節係数 ＝ 前年当月の客単価 ÷ 前年の先月・先々月の客単価
