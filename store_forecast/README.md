# 日別客数予測ツール

時間帯別売上実績表（先月・先々月）を貼り付けると、当月の日別・時間帯別の予測客数を出す Excel ツール。

- `日別客数予測ツール.xlsx` … 空のテンプレート（使い方はブック内「使い方」シート）
- `build_forecast_tool.py` … テンプレート生成スクリプト（祝日追加や時刻列の変更はここを編集して再生成）

```
python build_forecast_tool.py 出力.xlsx [先月データ.xlsx] [先々月データ.xlsx]
```

## 予測式

予測客数 ＝ 日タイプ別基準客数 × 季節係数 × トレンド係数 × 日別補正

| 要素 | 内容 |
|---|---|
| 日タイプ | 月〜日＋祝（祝日シート）の8区分 |
| 基準客数 | 先月・先々月の日タイプ別平均（休業日除外）を 0.6:0.4 で加重平均 |
| 季節係数 | 前年当月の客数合計を入力すると、前年の「先月・先々月→当月」の伸び率で補正 |
| トレンド係数 | 手入力（参考に前年比を表示） |
| 日別補正 | イベント・天候など日ごとの倍率 |
